# LNP-SAM

LNP-SAM measures lignin nanoparticles in TEM and SEM microscope images. The pipeline cleans each image and reads its scale bar, uses Meta's Segment Anything Model (SAM) to propose candidate particle masks, groups and classifies those proposals, and reports per-particle sizes with summary statistics. You use it through a PySide6 desktop app with an overlay viewer showing particle IDs, a size distribution plot, summary statistics, a sortable particle table and zip export. To install, create a Python 3.11 environment, run `pip install -r requirements.txt`, and start the app with `python -m lnpsam.gui`. Local processing needs the official SAM ViT-B checkpoint (`sam_vit_b_01ec64.pth`, downloaded separately from Meta) and its SHA-256 hash, both set under `sam:` in `config.yaml`; the app refuses to run if the hash is missing or does not match. EasyOCR downloads its own models on the first run. Processing can also happen on another machine: start `python -m lnpsam.server --host 0.0.0.0 --port 8765 --token <secret>` on a GPU computer or HPC compute node, then choose Remote server in the app and enter the address and token. The server has no HTTPS, so use it only on a lab network or through an SSH tunnel. Results from either mode are saved under `~/LNP-SAM runs/` and can be reopened later with `python -m lnpsam.gui --results <folder>`. To run the tests, install `requirements-dev.txt` and run `QT_QPA_PLATFORM=offscreen python -m pytest -q`; SAM and OCR are faked, so no model weights are needed. The project is a work in progress: accuracy on real images is not yet fully validated, and the microscope images used during development are not included in this repository.
